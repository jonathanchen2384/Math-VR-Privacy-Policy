Privacy Policy for Quadratic Function Extrema App

Quadratic Function Extrema App is built to help users learn and interact in VR without collecting personal data. This page explains what the app does and does not do with user information.

Read the policy Contact

At a glance

Quadratic Function Extrema App does not collect, store, transmit, sell, rent, or share personal data. The app only uses local device preferences to save temporary interface settings such as screen positioning so the app behaves smoothly for the user.

  • No accounts
  • No analytics
  • No cloud sync
  • No ad trackers
  • Local temporary settings only

Effective date: April 30, 2026

1. Introduction

This Privacy Policy describes how Quadratic Function Extrema App handles information when users access and use the Quadratic Function Extrema App application on Meta Quest and related platforms. Quadratic Function Extrema App is designed to function without collecting personal data from users.

2. Data We Collect

Quadratic Function Extrema App does not collect personal data from users.

Specifically, Quadratic Function Extrema App does not collect or store:

  • Names, email addresses, phone numbers, or mailing addresses
  • Account credentials or profile information
  • Payment information
  • Biometric information
  • Voice recordings
  • Photos, videos, or camera data
  • Precise location information
  • Analytics tied to an identifiable user
  • Cloud-saved personal data

3. Local Device Preferences

Quadratic Function Extrema App uses local device storage, such as player preferences, only to store temporary app settings that improve the user experience. For example, these preferences may store interface or screen-positioning choices so the app can reopen smoothly and maintain a comfortable layout.

These local preferences:

  • are stored only on the user's device;
  • are not used to identify a person;
  • are not transmitted to the developer or third parties; and
  • are used only for app functionality and quality-of-experience purposes.

4. How Information Is Used

Because Quadratic Function Extrema App does not collect personal data, there is no personal data used for advertising, profiling, analytics, marketing, resale, or user tracking.

Local device preferences are used only to preserve temporary functional settings within the app.

5. Data Sharing and Disclosure

Quadratic Function Extrema App does not sell, rent, license, trade, or otherwise share personal data with third parties because no personal data is collected by the app.

Local preferences used by the app remain on the user's device unless the operating system, device owner, or user removes the app data.

6. Data Retention

Since Quadratic Function Extrema App does not collect or store personal data on developer-controlled systems, there is no retained personal data database associated with app usage.

Temporary local device preferences may remain on the device until the user clears app data, reinstalls the app, resets the device, or removes the app through the device's normal controls.

7. Data Deletion Requests

Because Quadratic Function Extrema App does not collect or maintain personal data, there is generally no personal data for the developer to access, correct, export, or delete.

If a user would like to remove the app's locally stored temporary preferences from their device, they can do so by uninstalling Quadratic Function Extrema App or clearing the app's local data using available device or operating system controls.

If you have a privacy question or would like to request confirmation regarding this policy, please use the contact information below.

8. Children's Privacy

Quadratic Function Extrema App is not intended to knowingly collect personal data from children or adults. As described above, the app is designed not to collect personal data from any user.

9. International Users

Because Quadratic Function Extrema App does not collect personal data on developer-controlled servers, the app does not engage in cross-border transfers of personal data by the developer as part of ordinary app use.

10. Security

Quadratic Function Extrema App is designed with data minimization in mind. By avoiding collection of personal data, the app reduces privacy and security risk. Any temporary settings stored locally are limited to functional app preferences.

11. Third-Party Services

Quadratic Function Extrema App does not use third-party advertising SDKs, analytics SDKs, or external data processors for collecting personal data through the app, based on the current version of the product.

If future versions of Quadratic Function Extrema App introduce features that involve personal data, this Privacy Policy will be updated before those features are made available as required.

12. Legal Bases and Privacy Rights

Because Quadratic Function Extrema App does not collect personal data, many privacy rights requests that apply to collected personal data will not be applicable in practice. However, users may still contact the developer with questions about privacy, data handling, or local storage behavior.

13. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect app changes, platform requirements, or legal obligations. The updated version will be posted at this URL with a revised effective date.
