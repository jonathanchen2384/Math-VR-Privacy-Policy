# Math VR Privacy Policy Site

This is a static website suitable for GitHub Pages hosting.

## Files
- `index.html` - main privacy policy page
- `styles.css` - styling for the page

## Before publishing
1. Open `index.html`
2. Replace `replace-with-your-email@example.com` with your real contact email
3. Commit the files to a GitHub repository
4. Enable GitHub Pages in the repository settings

## GitHub Pages quick setup
1. Create a repository, for example `math-vr-privacy`
2. Upload `index.html` and `styles.css` to the root of the repository
3. In GitHub, go to **Settings > Pages**
4. Under **Build and deployment**, choose **Deploy from a branch**
5. Select your main branch and the `/ (root)` folder
6. Save
7. GitHub will publish your site at a `github.io` URL

## Suggested Meta submission URL
Use the final GitHub Pages URL for the app's Privacy Policy field in the Meta developer dashboard.
